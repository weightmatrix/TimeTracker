# TimeTracker 开发手册

> 目标：给维护者一份“从功能到操作到实现”的完整地图。本文以代码事实为基准，尽量覆盖现有模块与真实操作路径。若界面与文案调整，以实际 UI 为准。

---

## 1. 项目总览

**产品定位**
- 时间记录 + 任务/档案/教案/教学流程 + 小组件与 Live Activity。
- 同时支持 iOS 与 macOS（包含非 Catalyst 适配）。

**核心入口**
- App 入口：`TimeTracker/TimeTracker/TimeTrackerApp.swift`（`@main`）
- Widget 入口：`TimeTracker/TimeTrackerWidget/TimeTrackerWidget.swift`

**运行时状态容器（EnvironmentObject）**
由 `TimeTrackerApp` 注入：
- `TimeStore`：计时主数据
- `EfficiencyStore`：效率数据
- `TaskStore`：任务
- `CalendarStore`：日历
- `ArchiveStore`：档案/模板/教案等核心文件数据
- `GlobalSettingsStore`：全局设置
- `PurchaseManager`：内购
- `DetailedCategoryStore`：详细统计
- `TeachingStore`：教学状态（单例）

> 代码位置：`TimeTracker/TimeTracker/TimeTrackerApp.swift`（`TimeTrackerApp`）

## 2. 目录结构与文件职责

**顶层结构**
- `TimeTracker/TimeTracker/`：主 App 代码（大量逻辑集中在 `TimeTrackerApp.swift`）
- `TimeTracker/TimeTrackerWidget/`：Widget 与 Live Activity
- `TimeTracker/markdown_assets/`：Markdown/KaTeX 资源
- `TimeTracker/Frameworks/`：内置 Framework 头文件
- `TimeTracker/TimeTrackerTests/`、`TimeTracker/TimeTrackerUITests/`：测试

**关键文件**
- `TimeTracker/TimeTracker/TimeTrackerApp.swift`：主 UI + 业务核心（体量极大）
- `TimeTracker/TimeTracker/CloudFileManagerIO.swift`：iCloud 原子读写骨架
- `TimeTracker/TimeTracker/UbiquityContainerProvider.swift`：iCloud 容器解析与缓存
- `TimeTracker/TimeTracker/LocalDataManager.swift`：无 iCloud 本地导出/保存
- `TimeTracker/TimeTracker/TelemetryEvents.swift`：遥测事件定义

## 3. 启动与生命周期

**启动流程（简化）**
1. `TimeTrackerApp` 创建各 Store，并注入 `MainView` 或 `OnboardingView`。
2. `onAppear` 中执行：
   - `PomodoroManager` 初始化
   - iCloud 数据恢复
   - 购买状态刷新
   - 云端监听器启动
   - 效率缓存刷新
3. App 进入后台或 inactive 时触发全量物理备份。

**代码位置**
- `TimeTracker/TimeTracker/TimeTrackerApp.swift` → `TimeTrackerApp` 的 `onAppear` 和 `scenePhase` 监听

## 4. 数据结构与存储模型

### 4.1 数据类型
**表格/清单类型（核心）**
- `TableType.standard`：标准表格
- `TableType.taskList`：任务清单
- `TableType.markdown`：Markdown 文档
- `TableType.lessonPlanNodes`：教案/随堂笔记节点

**模板类型**
- `TemplateType.table`、`TemplateType.taskList`、`TemplateType.markdown`

**代码位置**
- `TimeTracker/TimeTracker/TimeTrackerApp.swift`（`TableType`、`ArchiveTemplate.TemplateType`）

### 4.2 iCloud 容器与文件结构
**容器解析**
- 通过 `DefaultUbiquityContainerProvider` 解析并缓存 iCloud Documents 路径。
- 支持重试、负缓存、Keychain 记录最后成功容器。

**代码位置**
- `TimeTracker/TimeTracker/UbiquityContainerProvider.swift`

**关键根目录（逻辑层识别）**
- `记录/` `表格/` `设置/` `导入/` `模板/` `教案/`

**代码位置**
- `TimeTracker/TimeTracker/TimeTrackerApp.swift`（`CloudSyncManager` 的路径识别逻辑）

### 4.3 本地导出
- `LocalDataManager` 负责 JSON 保存、CSV 导出、导出路径获取。
- CSV 带 BOM，确保 Excel 正确识别中文。

**代码位置**
- `TimeTracker/TimeTracker/LocalDataManager.swift`

### 4.4 遥测与日志
- `TelemetryEvents` 预定义 iCloud 相关事件。
- `Telemetry.log` 会写入 `DebugLogCenter`（云端静默日志）。

**代码位置**
- `TimeTracker/TimeTracker/TelemetryEvents.swift`
- `TimeTracker/TimeTracker/TimeTrackerApp.swift`（`DebugLogCenter`）

## 6. 功能与操作说明（按钮级/逐页面清单）

**页面入口**

**代码位置**

### 6.2 任务（Tasks）
**页面入口**

**代码位置**

## 7. Widget 与 Live Activity

**用户操作**
- 桌面或锁屏组件一键切换时间分类。
- iOS 灵动岛展示当前计时。

**关键实现点**
- `StartTimerIntent`：写入 AppGroup 同步状态并触发刷新。
- `WidgetCenter.shared.reloadAllTimelines()` 刷新小组件。
- Live Activity 基于 `ActivityKit` 更新。

**代码位置**
- `TimeTracker/TimeTrackerWidget/TimeTrackerWidget.swift`

## 8. iCloud 同步与冲突处理

**原子读写**
- `CloudFileManagerIO` 里封装 `NSFileCoordinator` 原子读写。

**容器解析**
- `DefaultUbiquityContainerProvider`：缓存容器 URL，处理身份变更。

**冲突解决**
- 选最后修改时间的版本为 winner，并替换主文件。

**代码位置**
- `TimeTracker/TimeTracker/CloudFileManagerIO.swift`
- `TimeTracker/TimeTracker/UbiquityContainerProvider.swift`

---

## 9. 备份与恢复

**自动备份**
- 通过 `BackupManager.shared.saveFullFolderSnapshot(...)` 物理拷贝 iCloud 根目录。

**触发时机**
- App 进入后台/inactive
- 手动触发通知 `TriggerManualFullBackup`

**代码位置**
- `TimeTracker/TimeTracker/TimeTrackerApp.swift`（`performAutoBackup`）

---

## 10. 性能排查清单

**教案按钮慢**
- 侧边栏打开时逐条读取母本 CSV。
- `TeachingLessonSidePanel.loadData(for:)` 内部 IO 高。

**建议排查顺序**
1. 教案清单条目数
2. 母本 CSV 文件数量
3. 是否触发 `performTeachingSync`

**代码位置**
- `TimeTracker/TimeTracker/TimeTrackerApp.swift`（`TeachingLessonSidePanel`）
